# v0.3.0 · Web 开源首发

这是「轮盘人生（Wheel of Life）」的首个公开 Web 版本：一个以中文为主的随机人生 / 命运转盘游戏。

## 本次发布

- 发布 React + TypeScript + Vite Web 端。
- 完成角色创建、命运转盘、阶段事件、成长与结局流程。
- 引擎、存档、内容包校验与 UI 测试纳入 CI。
- 提供 GitHub Pages 在线试玩地址。
- 公开 MIT 许可下的原创基础内容与代码。

## 暂不包含

- 微信小程序、抖音小程序本轮冻结，不作为本版本交付目标。
- 版权敏感的个人 / 同人内容包不会进入仓库或 Release Assets。

## 本地运行

```bash
npm install
npm run dev
```
